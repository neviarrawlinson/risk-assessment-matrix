# 📊 Risk Assessment Matrix Generator

The **Risk Assessment Matrix Generator** is a Python tool that helps visualize risks based on their probability and impact. It reads risk data from a CSV file and generates a color-coded heatmap to highlight high-risk areas.

## 🚀 Features
- Import risk data from a CSV file
- Generate a dynamic **Risk Assessment Matrix (Heatmap)**
- Color-coded visualization for easy risk identification
- Export the matrix as an image (`risk_matrix.png`)
